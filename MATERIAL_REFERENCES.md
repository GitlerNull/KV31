# Level 0 material references

The Level 0 material pass was planned against real internet references, not generated concept art:

- The historical Backrooms room photograph and its low-ceiling office environment: https://www.404media.co/internet-sleuths-trace-the-backrooms-creepypasta-to-an-rc-car-race-track-in-wisconsin/
- Yellowed wallpaper and damp carpet description used for Level 0 visual context: https://backrooms.fandom.com/wiki/Level_0
- CC0 aged wallpaper material reference: https://ambientcg.com/view?id=Wallpaper001B
- CC0 beige loop-pile carpet material reference: https://ambientcg.com/view?id=Carpet016
- CC0 mineral-fibre suspended ceiling reference: https://ambientcg.com/view?id=OfficeCeiling001
- CC0 office ceiling tiles with seamless option: https://opengameart.org/content/ceiling-tile-texture

The repository does not redistribute those reference photographs or texture files. The game's existing renderer creates its own small procedural albedo maps at startup. The code changes use the online references for the material characteristics only: muted aged yellow wallpaper, fine beige/brown carpet pile, speckled acoustic ceiling panels, and recessed fluorescent fixtures.

The ambientCG material assets are released under CC0 according to the asset pages. The OpenGameArt ceiling-tile pack is also marked CC0 on its asset page. The original Backrooms photograph is a visual reference only and is not bundled in the game.
